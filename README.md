# blender-material-variant-generator

A Blender add-on that generates color and roughness variants of selected materials for batch previewing.

## Stack

Primary language: **Python**

## Project structure

- `blender_material_variant_generator.py` — Generate material variants for selected objects
- `requirements.txt` — dependencies
- `tests/test_main.py` — basic tests

## Usage

Review the source files and install any dependencies referenced by the project before running it.
